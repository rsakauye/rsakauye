### About

I started at Jet Cooper, grew into helping run the office, and worked on the audit behind its acquisition by Shopify. At Shopify (2013 to 2022) I went from Office Manager to Facilities Manager, Junior Project Manager, and Project Operations Analyst in the PMO. Most of those roles were created because I spotted a gap and fixed it.

I've held my PMP since 2018. Today I build and run a team of AI agents with a pull request workflow, and I approve the work before anything ships.
